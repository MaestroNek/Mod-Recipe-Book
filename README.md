# Mod Recipe Book

Adds a recipe book for modded recipes.

For players who want modded Minecraft without every recipe unlocked from the start. You find items, unlock crafts, and learn mod content as you go. The book is configurable for your own modpack: custom categories with any set of mods, hide the vanilla recipe book, and whether a recipe unlocks from one item or from every ingredient.

Recipe layouts come from [JEI](https://github.com/mezz/JustEnoughItems).

## Features

- Own recipe book button on inventory, crafting table, and furnaces
- **All Recipes** tab plus up to **5 custom categories** (pick mods; Minecraft can be included)
- Left click a recipe to place it in the grid; right click to open the item recipes layout
- Recipes unlock when you find items. By default a recipe unlocks only after you have found every ingredient. Finding an item also unlocks recipes that craft that item
- When the vanilla book is disabled, vanilla recipes appear in **All Recipes**

## Requirements

- NeoForge
- JEI

## Install

Put `modrecipebook-1.0.0.jar` in the `mods` folder together with NeoForge and JEI.
